## Goal

Remove the stale `main.js` from the repository root and separate source
icons from build output so the `electron/build/` directory contains only
electron-builder artifacts.

## Background

- `./main.js` is a duplicate of `electron/main.js` (older version, no
  `app.isPackaged` check for `backend.py` path). It's confusing and
  should never have been committed.
- `electron/build/` currently stores both source icons (`icon.icns`,
  `icon.png`, `icons.iconset/`) AND electron-builder output (`.dmg`,
  `.blockmap`, `builder-debug.yml`). This is messy and risks icon
  deletion during clean builds.

## Implementation

### 1. Delete `./main.js`

```bash
git rm main.js
```

### 2. Create `electron/assets/` for source icons

```bash
mkdir -p electron/assets
mv electron/build/icon.icns electron/assets/
mv electron/build/icon.png  electron/assets/
mv electron/build/icons.iconset electron/assets/
```

### 3. Update `electron/package.json` icon paths

Change:
```json
"mac": {
    "icon": "build/icon.icns",
    ...
}
```
→
```json
"mac": {
    "icon": "assets/icon.icns",
    ...
}
```

Similarly for `win.icon` and `linux.icon`.

### 4. Update `scripts/bundle-python.js` icon generation paths

Change icon generation to write to `electron/assets/` instead of
`electron/build/`.

### 5. Update `.gitignore`

Add `electron/assets/` if icons should not be tracked (they can be
generated by the bundle script). Keep `electron/build/` excluded.

If icons should be tracked (recommended — they rarely change), add
a comment in `.gitignore`:
```
# Electron build artifacts
electron/build/
electron/bundle/
electron/node_modules/
```

### 6. Verify no stale references

Search for any code referencing `electron/build/icon.icns` or
`./main.js` and update paths.

## Validation

```bash
# Verify root main.js is gone
test ! -f main.js && echo "OK: root main.js deleted"

# Verify icons moved
test -f electron/assets/icon.icns && echo "OK: icon.icns in assets"
test -f electron/assets/icon.png && echo "OK: icon.png in assets"

# Verify package.json references updated
grep -c '"icon": "assets/' electron/package.json && echo "OK: package.json paths updated"

# Verify bundle script references updated
grep -c 'assets/' scripts/bundle-python.js && echo "OK: bundle script paths updated"

# Verify build still works
npm --prefix electron run build:mac
test -f electron/build/SplitShot-*.dmg && echo "OK: build produces .dmg"
```
