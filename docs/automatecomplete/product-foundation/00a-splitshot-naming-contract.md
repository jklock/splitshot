# SplitShot Naming Contract

This contract is binding for Automate3 implementation, UI copy, tests, docs, and release language.

## User-Facing View Names

Use these exact names:

- `Landing Page`
- `Stage Video Edit`
- `Match Video Edit`
- `Performance Library`

## Internal Identifiers

Existing internal identifiers may remain where already established:

- `landing`
- `single`
- `multi`
- `library`

Do not expose `single` or `multi` to users unless a legacy test or internal-only code path requires it.

## Allowed Product Language

Use:

- stage
- match
- performance history
- retained proxy
- output profile
- review source
- shared defaults
- stage overrides
- setup once
- apply everywhere

## Forbidden Product Language

Do not call SplitShot:

- a video maker
- a content creator
- a generic timeline editor
- a Shotcut clone

Do not copy competitor-facing labels when a SplitShot-native label exists.
