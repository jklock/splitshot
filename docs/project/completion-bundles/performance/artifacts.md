# Performance Artifact Plan

## Purpose

This file tracks the proof package required to call the Performance shared-shell reset complete.

## Required evidence categories

### 1. Test evidence

Record exact test outputs for Performance-owned or Performance-impacted coverage:

- static Performance shell contracts under the shared shell
- library/backend route behavior
- record browsing, lower-pane detail, and reopen flows
- notes/tags persistence behavior
- analytics behavior
- backup and export behavior
- browser control inventory and coverage audits where Performance controls changed

### 2. Visual evidence

Required screenshots:

- Performance empty state under the shared shell
- Performance overview with summary tiles in the main area
- Performance records/detail view with the lower pane populated
- Performance analytics section
- Performance backup section
- Performance settings section

### 3. Output evidence

Capture and link output or persistence proofs for:

- open stage and open workspace targets
- notes and tags persistence
- backup create and restore behavior
- CSV and JSON export behavior
- analytics evidence where screenshots alone are insufficient

### 4. Documentation evidence

Link all synchronized doc updates for:

- QA matrix
- coverage plan
- full browser E2E plan
- user-facing Performance docs
- completion-bundle ledgers updated during Performance reset

- Test run summary:

  - Notes: prefer targeted `.venv` output first, then the owning suite

  - Notes: include a purpose-specific folder if generated by script
- Backup/export outputs:
  - Expected path: `artifacts/` or the emitted output path recorded during validation
  - Notes: record the exact scenario exercised
