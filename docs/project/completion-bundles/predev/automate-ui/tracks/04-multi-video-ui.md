# Track 04: Multi Video UI

## Goal

Expose the workspace model as a real match-level editing surface.

## Required Workspace UI

- workspace create/open/save
- stage grid
- stage open/return flow
- shared defaults
- stage overrides

## Required Stage Grid Fields

- display name
- stage number
- completeness status
- missing media
- override present
- last reviewed

## Required Separate Editors

### Match Recap

- stage inclusion/exclusion
- stage order visibility
- result-card controls
- match-scope output-profile render action

### Stage Composite

- clip list
- add/update/remove clip
- angle role editor
- Angle Align controls
- audio mix lane controls
- cut override plan editor
- composite render action

## Acceptance

- the workspace is no longer implicit or route-only
- Match Recap and Stage Composite remain separate flows in UI and proof
