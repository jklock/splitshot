# Track 05: Performance Library UI

## Goal

Make the library a real historical browse-and-reopen surface.

## Required UI

- summary tiles
- filter/search/sort controls
- record table
- selected-record detail panel
- retained proxy status panel

## Required Actions

- open retained proxy
- refresh retained proxy
- open stage editor
- open match workspace

## Required States

- empty history
- stale proxy
- missing proxy
- unresolved reopen target
- ready reopen target

## Acceptance

- the user can browse, inspect, and reopen historical work without dropping back into a hidden route model
