# Media Pane

The Media pane pairs media with each project stage. Each stage can keep one primary video and any number of added media items.

## Use This Pane For

- Reviewing the project stage list.
- Selecting the active stage.
- Importing or replacing a stage primary video.
- Importing added media for a stage.

## Key Controls

| Control | What it does |
| --- | --- |
| Stage row | Selects the active stage without leaving Media. |
| `+ Primary` / `↻ Primary` | Imports or replaces that stage's primary video. |
| `+ Added` | Adds secondary media to that stage. |
| `Primary Media` | Shows the current primary file name for the row. |
| `Added Media` | Shows the current added-media count for the row. |

## Workflow

1. Import PractiScore data in [project.md](project.md) first when stage records are available.
2. Open Media.
3. Select the stage you want to edit.
4. Import the primary video for that stage.
5. Add the secondary angle or other supporting media for that stage.
6. Repeat for every stage in the project.
7. Move to [pip.md](pip.md) to configure the active stage composition.

## Notes

- One stage is active at a time across Compose, Trim, Score, Splits, Markers, Overlay, Review, Export, and Metrics.
- Stage media is stage-local. Switching stages swaps the full editing context.
- The active row is highlighted so you can see which stage the rest of the app is editing.
