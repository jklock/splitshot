# Media Pane

The Media pane is the stage media workspace. Each stage lives inside a collapsible card with file rows for the primary video and any added media.

## Use This Pane For

- Reviewing the project stage list and collapsing or expanding stages.
- Selecting the active stage.
- Viewing and managing file rows for primary and added media.
- Setting the primary video from any attached file.
- Adding more media files to a stage.
- Removing files from a stage.
- Entering the live editing pipeline via Edit Stage.

## Key Controls

| Control | What it does |
| --- | --- |
| Stage card toggle (▸ / ▼) | Expands or collapses the stage card. |
| Stage header | Shows the stage label and stage number. |
| File row | Shows one attached file with its filename, type, duration, and dimensions. |
| `Primary` badge | Marks the current primary file for that stage. |
| `Set Primary` | Imports a new primary video for that stage. |
| `Remove` | Removes that file from the stage. |
| `Add More` | Adds additional media files to the active stage. |
| `Edit Stage` | Makes the stage live and keeps you in Media for further work. |

## Workflow

1. Import PractiScore data in [project.md](project.md) first when stage records are available.
2. Open Media.
3. Expand the stage you want to work on.
4. Import a primary video for that stage.
5. Add more files with Add More.
6. Set the primary designation on the file row you want.
7. Remove any files that do not belong.
8. Click Edit Stage to make that stage live.
9. Repeat for every stage in the project.
10. Move to [pip.md](pip.md) to configure the active stage composition.

## Notes

- One stage is active at a time across Compose, Trim, Score, Splits, Markers, Overlay, Review, Export, and Queue.
- Stage media is stage-local. Switching stages swaps the full editing context.
- The active stage card is highlighted so you can see which stage the rest of the app is editing.
- Competitor identity selectors live in Project, not here. Media owns stage files and edit entry only.
