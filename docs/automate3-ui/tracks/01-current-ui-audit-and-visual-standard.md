## Current Failures

- surfaces are not true separate views
- automation controls are bolted onto the editor
- Match and Library inherit editor chrome
- visual hierarchy is weak
- navigation layers compete
- empty states look unfinished
- controls feel dense without being organized
- current screenshots do not meet user-ready quality.

## Shotcut Adaptation

Adapt:

- preview/timeline/inspector hierarchy
- coherent editor density
- purposeful modal flows
- persistent context
- restrained, consistent controls.

Do not copy:

- branding
- product names
- exact layouts
- iconography
- competitor workflow language.

## Visual Standard

The final UI must look like a professional analysis editor. It should be dense where useful, calm where decisions matter, and obviously organized by user task.
